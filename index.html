26-Week Progress Log

April 2026 (Weeks 1 - 4)

Orientation & Data Familiarization

Completed onboarding and HR briefings. Spent the first month understanding the legacy reporting structures and observing how the team handles raw data imports. Began mapping out the bottlenecks in the current manual copy-pasting process.

May 2026 (Weeks 5 - 8)

Introduction to Power Query

Proposed shifting from manual data entry to dynamic data transformation. Built my first multi-file append query using Power Query to consolidate daily branch reports into a single master sheet automatically.

Key achievement: Reduced consolidation time by 20%.

June - Mid July 2026 (Weeks 9 - 14)

Advanced Excel Functions & Formula Logic

Re-engineered the dashboard logic. Replaced hundreds of heavy, volatile VLOOKUPs with optimized INDEX/MATCH, LET, and VSTACK functions. This significantly reduced the file size and prevented Excel from freezing during calculations.

Late July - Aug 2026 (Weeks 15 - 20)

VBA Automation Breakthrough

Started writing custom VBA scripts to handle repetitive formatting, data cleansing, and email distribution. Created a 1-click macro button that processes the daily report, formats the tables, and saves it in the shared drive.

  • Automated error handling for missing data.
  • Report generation time dropped from 45 mins to 5 mins.
September 2026 (Weeks 21 - 26)

Project Handoff & Wrapping Up

Finalized the documentation for all Power Query models and VBA scripts. Conducted a training session for the department staff on how to use the new automated tools. Completed my final practicum presentation to the supervisor and finalized my HR exit process.
